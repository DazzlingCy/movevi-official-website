# MOVEVI 桌面官网设计规范

本轮参考 https://www.apple.com/ ，查阅于 2026-10-13。借鉴中性色、蓝色操作入口、清晰的文字层级、大幅实景和圆角卡片；不使用 Apple 标识、产品图片或文案。MOVEVI 原始 Logo、真实 App 界面及产品素材保持原样。

## 颜色

| 用途 | 色值 |
| --- | --- |
| 页面底色、卡片 | `#FFFFFF` |
| 交替区块、轻背景 | `#F5F5F7` |
| 主标题、正文 | `#1D1D1F` |
| 次级文字 | `#6E6E73` |
| 主操作 | `#0071E3` |
| 文本链接 | `#0066CC` |
| 分割线 | `#D2D2D7` |
| 分段选择底槽 | `#E8E8ED` |

品牌 Logo 保留红橙色；摄影和视频保持自然颜色。影像上的文字使用白色，并保留黑色渐变遮罩确保可读性。大标题主要使用深灰，蓝色用于操作和选中状态。

## 排版与组件

- 系统无衬线字体栈：Apple 设备优先系统字体，Windows 使用 Segoe UI，中文使用系统中文字体。无需下载专属字体。
- 标题使用 600 字重，首屏使用 650；短行与紧凑字距，正文使用灰色和舒适行高。
- 主按钮为蓝色胶囊，次级操作为蓝色文字链接；统一悬停及键盘焦点。
- 主要图片卡片圆角 28px，App 展示区 32px，步骤卡片 16px；轻阴影只用于必要的浮层与交互反馈。
- 城市选择和产品系列采用灰色分段选择底槽，白色选中态。App 当前步骤为白底蓝边。
- 弹窗、图库缩略图、参数表、FAQ 与页尾沿用同一配色。

## 实现边界

统一样式入口为 `dist/design-system.css`，在原有组件样式之后加载。规则限定桌面宽度大于 900px；手机和平板布局等待用户确认网页版后统一适配。

保留原生滚动、每个叙事板块的一屏高度、透明导航折叠、Three.js 地球鼠标交互、滚动入场、城市拖动及中间视频播放、App 步骤切换、产品与客服弹窗。遵循系统减少动态和节省流量设置，视频继续在离屏或后台暂停。未新增第三方依赖、登录或外部素材。
