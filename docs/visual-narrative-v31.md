## 节奏与降级

- 白 / #f5f5f7 / #1d1d1f / #0071e3，保留原始 Logo。城市卡片统一 28px 圆角、明确底部标题；标题字号分级，正文限制行宽。
- 仅问题、洞察、解决方案短程 sticky；其余原生连续滚动。标题先于解释和图像，正文不逐字动画。
- 桌面解决方案是可逆滚动时间线。移动、平板、短屏及减少动态设置改为城市 → 路线 App → 硬件的自然图文顺序，不保留空白固定距离。
- 新时间线使用被动滚动事件与按需 requestAnimationFrame，不接管 wheel；离屏与后台停止计算。保留原有地球、视频生命周期及键盘操作。
- 不新增 AI 能力、联动承诺、评价或真实覆盖统计。四款硬件与图库、参数对比、客服、章节导航均保留。

## 本地验证

- 浏览器检查 1440 × 900、1366 × 768 桌面，820 × 1180 平板，390 × 844 手机；所检查视口无横向页面溢出。
- 实际滚动检查城市放大、路线 App、运动界面与 TS3 同框，以及向上回滚的城市卡片交接。卡片移动期间让出标题阅读空间。
- 手机、平板使用自然图文布局；修正图片固有高度造成的空白。无人产品渲染与背景融合，照片上的标题维持白字对比度。
- 实际操作 TS3 图库视角、完整参数对比、TS2 系列切换、客服弹窗和巴黎城市选择；城市区域仅当前视频播放。
- `npm run check` 覆盖素材、锚点、四款产品、地球与视频生命周期、章节顺序、原有滚动交互；新增城市 / App / 硬件时间线、反向滚动、遮挡暂停、后台 / 离屏停止和静态降级检查。
