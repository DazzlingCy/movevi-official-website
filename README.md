# MOVEVI 木卫六官网

根据 2026 年 10 月《MOVEVI 木卫六品牌手册 全新版》与本地木卫六 App 2.0 制作的中文品牌官网。

## 运行

使用 Node.js，无需安装依赖。

```sh
npm run dev
# http://127.0.0.1:4173/
npm run check
```

`dist/` 即完整静态网站，可部署到支持静态文件的服务器。`scripts/serve.mjs` 是本地预览服务器，不是生产服务。

## 页面与交互

2026-10-13 视觉叙事改版：巴黎氛围视频与真实 TS3 产品首屏 → 持续运动的动力 → 城市窗口滚动展开 → 四步真实 App 原型 → 可切换城市 → 品牌使命 → 产品图库与参数 → 企业微信咨询。采用红橙、炭黑与暖白。保留原生滚动；手机改为顺序叙事。支持视频手动暂停、离屏/后台暂停、节省流量和系统/站内减少动态效果。

智能硬件区收录 TS2、TS3、TS5、TS6 四个系列共八款产品，提供系列切换、完整参数对比、单型号详情及产品咨询。TS3 与 TS3 PRO 各有五张多角度渲染图，支持缩略图和键盘切换。

- `dist/index.html`：页面内容、语义结构、分享信息。
- `dist/styles.css`：品牌视觉、响应式排版与交互状态；`dist/brand.css` 统一硬件区暖色。
- `dist/app.js`：目的地与真实 App 截图切换、导航、客服弹窗。
- `dist/motion.js`：滚动转场、入场动效、视频生命周期及减少动态效果。
- `dist/media-config.js`：两段视频的桌面/手机地址、海报与用途。
- `dist/globe.js`、`dist/world.css`：延续 App 夜景地球风格的原生 WebGL 交互；拖动、方向键转动、城市标记和画面联动。无持续自转，离屏/后台停止更新；不支持 WebGL 时保留真实地理 SVG。
- `docs/globe-provenance.md`：App 世界页参考、NASA 夜景图与同源地理数据记录。地球纹理 66 KB，静态降级 SVG 50 KB，无新增运行依赖。
- `docs/media-provenance.md`：视频作者、原始页面、授权与 App 截图来源。
- `dist/products-data.js`：八款产品的参数、原表单元格溯源和图库配置。
- `dist/products.js`、`dist/products.css`：产品浏览、图库、参数对比及响应式样式。
- `docs/product-provenance.md`：型号与图片映射、数据规范化说明和用户确认的尺寸修正。
- `dist/assets/`：本地化的城市图、App 原型截图和客服二维码。
- `.openai/hosting.json`：Sites 身份与静态部署目录。

## 已完成检查

- Node 语法、静态资源存在性、内部锚点、唯一 ID 与单一 H1。
- 浏览器 390 × 844 手机、768 × 1024 平板和 1440 × 960 桌面检查。
- 手机菜单、目的地视频/海报切换、客服二维码弹窗、Escape 关闭与焦点返回。
- 四步 App 标签键盘导航、产品图库/系列/参数对比、FAQ、图片加载及控制台检查。
- `scripts/check-motion.mjs` 覆盖视频延迟加载、手动暂停、后台暂停、城市切换、自动播放失败及手动重试、减少动态、节省流量和视频体积预算。
- 地球版检查：390 × 844、768 × 1024、1440 × 960 与 1440 × 800 无横向溢出；桌面城市栏与说明完整显示。验证拖动、方向键、城市标记、视频/海报联动、手机视频版本和减少动态恢复海报。
- `scripts/check-globe.mjs` 覆盖懒加载、无 WebGL/纹理/着色器失败时的静态图降级、城市事件、跨日界线最短旋转、动画结束不空转、离屏/后台停止、减少动态与图形上下文恢复。

浏览器检查使用 Codex 内置浏览器；完整长截图接口不可用，使用分段视口截图检查。
